# Plan 1.1: Flask & File Upload Foundation

## Objective
Establish the base Flask backend structure and implement the document upload endpoint, establishing the entry point for the AI Study Assistant.

## Context
- .gsd/SPEC.md
- .gsd/ARCHITECTURE.md

## Tasks

<task type="auto">
  <name>Initialize Flask App</name>
  <files>app.py, requirements.txt</files>
  <action>
    - Create the basic Flask application in `app.py`
    - Setup python package dependencies in `requirements.txt` specifically including Flask, werkzeug, and standard python-dotenv.
    - DO NOT implement RAG or routes here, just the skeleton that can run standalone.
  </action>
  <verify>python app.py should run without errors on port 5000</verify>
  <done>app.py is created and standard run execution works</done>

<task type="auto">
  <name>Document Upload Endpoint</name>
  <files>routes/upload.py, app.py</files>
  <action>
    - Implement `POST /upload` route in `routes/upload.py`
    - Handle standard file uploads (PDF, DOCX, TXT) and save them temporarily or process into memory.
    - Register the blueprint/route in `app.py`.
    - Avoid processing the text just yet; simply return a success JSON payload confirming the file name.
  </action>
  <verify>Pass a dummy text file to `/upload` via python requests or curl and expect 200 OK</verify>
  <done>Upload endpoint accepts and securely processes valid files</done>
</task>

## Success Criteria
- [ ] Flask backend spins up on designated port
- [ ] Uploading a document hits the `/upload` endpoint correctly and returns a 200 response
