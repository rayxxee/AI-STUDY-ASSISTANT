# Plan 2.3: Query Endpoint Integration

## Objective
Create the REST API endpoint that connects user queries to the complete RAG pipeline (Retrieval -> Generation) and returns the answer.

## Context
- .gsd/SPEC.md
- app.py
- routes/upload.py

## Tasks

<task type="auto">
  <name>Query POST Endpoint Integration</name>
  <files>routes/query.py, app.py</files>
  <action>
    - Create `routes/query.py` defining `query_bp`.
    - Implement `POST /query` expecting JSON with `{"question": "..."}`.
    - Import the global `vector_store` from `routes.upload` (or initialize a shared one safely).
    - Call `retrieve_context` using the `vector_store`.
    - Pass the query and retrieved context to `generate_answer`.
    - Return a JSON response `{"answer": "...", "context": [...]}`.
    - Register `query_bp` in `app.py`.
  </action>
  <verify>curl -X POST -H "Content-Type: application/json" -d '{"question":"What did I upload?"}' http://localhost:5000/query and receive a 200 OK with answer JSON</verify>
  <done>Query endpoint completely ties the RAG architecture together and responds via HTTP</done>
</task>

## Success Criteria
- [ ] `/query` API successfully orchestrates retrieval and generation back-to-back.
- [ ] The full Flask backend logic for the initial MVP is functional.
