# Plan 4.1: UI Foundation & Document Upload

## Objective
Establish the Streamlit app structure and implement a sidebar mechanism for users to upload study materials to the Flask backend.

## Context
- .gsd/SPEC.md
- routes/upload.py

## Tasks

<task type="auto">
  <name>Initialize UI and Upload Logic</name>
  <files>ui/app.py, requirements.txt</files>
  <action>
    - Add `streamlit` and `requests` to `requirements.txt`.
    - Create `ui/app.py`.
    - Set up a Streamlit layout with a title and a sidebar.
    - In the sidebar, add `st.file_uploader` supporting PDF, DOCX, and TXT.
    - Write a function that takes the uploaded file and sends it via `requests.post` (multipart/form-data) to `http://localhost:5000/upload`.
    - Display success/error `st.success` / `st.error` messages based on the Flask response.
  </action>
  <verify>Run `streamlit run ui/app.py` in a terminal (while Flask is running in another) and successfully upload a dummy text file through the web interface.</verify>
  <done>User can successfully push documents from the UI to the FAISS backend</done>
</task>

## Success Criteria
- [ ] Submitting a file through Streamlit correctly triggers ingestion on the Flask server.
