# Plan 4.2: Main Chat Interface

## Objective
Build the conversational UI that sends user questions to the Flask `/query` endpoint and displays the AI's response along with expanding context citations.

## Context
- .gsd/SPEC.md
- routes/query.py
- ui/app.py

## Tasks

<task type="auto">
  <name>Implement Chat Interface</name>
  <files>ui/app.py</files>
  <action>
    - In `ui/app.py` main panel, initialize `st.session_state.messages` to store local visual chat history.
    - Render existing messages using `st.chat_message`.
    - Accept user input via `st.chat_input`.
    - On input, display the user message immediately, then `requests.post` the `question` JSON to `http://localhost:5000/query`.
    - Display the returned `answer` and use an `st.expander` block beneath it to optionally show the `context_used` data so the user can verify the AI's citations against the original document chunks.
  </action>
  <verify>Interact with the Streamlit chat box and receive a generated answer with a clickable expander containing the source chunks.</verify>
  <done>Full conversational loop from UI to Vector DB to LLM and back is functional</done>
</task>

## Success Criteria
- [ ] The user can type questions and get rich text responses with verifiable source citations embedded in the UI.
